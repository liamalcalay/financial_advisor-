# AI Portfolio Analyst

An educational, research-only portfolio assistant. It will collect market context,
surface relevant news, and explain recommendations; it will not place trades.

## First milestone: read a portfolio

1. Update the sample positions in `portfolio.json` with your own holdings.
2. Run the application:

   ```powershell
   & "C:\Users\liama\AppData\Local\Programs\Python\Python313\python.exe" app.py
   ```

3. Run the tests:

   ```powershell
   & "C:\Users\liama\AppData\Local\Programs\Python\Python313\python.exe" -m unittest discover -s tests
   ```
